# BWER / P15 顶刊设计冻结：最终头脑风暴与执行判决

日期：2026-07-21  
目标：形成一篇指标/框架论文，并以四任务 GeoFM Fairness Validation Suite 提供实证验证；不建设重运营型公共 benchmark。

## 一句话判决

最终产品应命名为 **Certified BWER Profile（P15）**。P15 内部以严格的 weighted fractional BWER 作为唯一总体参数，同时输出描述性点估计、诚实确认下界、共同支持、配对推断、尾部稳定性和固定 beta profile。论文不再公开使用“BWER1/BWER2”作为两个并列指标：BWER1 只作为旧定义消融，最终公式统一称为 BWER。

新增实验的最优选择不是第五个任务，而是在现有任务上建立一个严格同协议的现代 GeoFM 对照面板：优先把 TerraMind 加入 Sen1Floods11 与 reBEN，并在 fMoW-Sentinel 上补 DOFAv2 或同级现代模型。这样直接加强“指标能跨模型揭示部署尾部风险”的核心主张，避免扩大论文边界。

## 1. P15 的最终结构

P15 不是另一个风险公式，而是一套从总体参数到可审计结论的完整产品：

1. population estimand：weighted fractional BWER；
2. descriptive estimate：全样本 apparent plug-in BWER；
3. statistical certificate：独立 discovery/evaluation 得到的 confirmed contrast 与单向下界；
4. uncertainty：空间/事件/地点聚类下的直接区间与模型配对差值区间；
5. identifiability：共同支持质量、缺失部署质量和标准化 positivity；
6. robustness：固定 beta profile、部署权重敏感性、尾部成员稳定性；
7. companion：EB-TV 描述全分布错误负担；
8. optional modules：Standardised、Selective、Conformal、Rich-LCB、SPAD/C-SWER。

正式结果卡的最小输出为：

\[
\left(m_\mu,\;T_{\beta,\mu},\;\mathrm{BWER}_{\beta,\mu},\;
\mathrm{LCB}_{\rm cert},\;\mathrm{CI},\;\mathrm{support\ mass},\;
\mathrm{tail\ stability}\right).
\]

## 2. 此前八项问题是否已经发现并有方案

| 问题 | 此前是否识别 | 已提出的解决方案 | 当前状态 |
|---|---|---|---|
| 旧公式 `ceil(beta*G)` 超取尾部 | 是 | exact fractional AVaR | 设计冻结，待实现 |
| cluster bootstrap 克隆 ID 被重新合并 | 是 | 每次抽中的 cluster 生成 replicate 内唯一 ID；先固定推断总体 | 已定位到代码，待修复 |
| `renormalize` 不是共同目标标准化 | 是 | strict common-support direct standardisation；无法识别时判无效或使用预注册层级模型 | 设计冻结，待实现 |
| 不同模型有效切片集合不同 | 是 | fixed common-support population 与 paired comparison | 设计冻结，待实现 |
| 分数纳入临界国家的解释 | 部分 | 报告 fractional boundary mass；将其解释为风险分布插值，并附 whole-slice sensitivity | 本轮进一步明确 |
| 部署权重 mu 改变科学问题 | 是 | 预注册主测度、协议签名、一个实质性敏感性测度 | 已写入设计，待进入配置 |
| 不同任务损失尺度不可直接排总榜 | 是 | 同一任务内部比较；任务合同固定 loss；不合成跨任务总分 | 已写入设计 |
| 尾部 ties 的数值与身份不同 | 是 | BWER 值保持 permutation-invariant；报告 tie set 和成员稳定性，不把字典序当科学结论 | 设计冻结，待实现 |

结论：八项中七项已在 7 月 18–19 日审阅中明确出现，第五项当时已有 `fractional boundary mass` 输出要求，但本轮才把“分数国家不能按字面解释”为正式表述规则。它们不是八个都仍未知，而是多数已有修复设计、尚未进入最终实现。

## 3. 本轮新发现的高价值改进

### 3.1 P15 应采用“点估计 + 证书”双轨

Repeated cross-fit 能切断同一噪声同时负责“选择最差组”和“抬高风险”的路径，但它估计的是 discovery 所选方向的真实差距，有限样本下通常低于 oracle BWER。因此：

- apparent BWER 保留为总体参数的描述性全样本估计；
- cross-fit 输出改称 confirmed contrast/certificate；
- 不把负 cross-fit 值截断后包装成无偏 BWER；
- 正式主张使用“一侧下界大于零”证明至少存在多少可复现尾部差距。

这使 P15 的逻辑更清楚：点估计回答“观察到多少”，证书回答“保守地至少能确认多少”。

### 3.2 普通 Wald 确认区间在 fMoW 支持量下失准

本轮使用 fMoW 145 个国家的真实支持分布进行 500 次零假设模拟。名义 95% 的普通正态/Wald 单向下界覆盖率约为 92.8%，假阳性约为 7.2%。高错误率和部分 evaluation fold 仅约 10 个样本使正态近似不可靠。

因此实现必须至少包含：

- 有界损失的有限样本 Hoeffding/Bernstein 证书作为严格保底；
- 经仿真校准的 cluster/bootstrap 或 multiplier-bootstrap 作为实用主区间；
- Wald 只作大样本诊断，不作为默认认证。

严格 Hoeffding 证书在当前支持量下非常保守，说明最终产品应同时提供“严格证书”和“经覆盖率验证的实用区间”，不能只选择其中一个。

### 3.3 可由同时风险置信带直接传播 BWER 区间

若对所有切片同时有

\[
|\widehat R_g-R_g|\le e_g,
\]

则由 AVaR 风险包络可得：

\[
|\widehat{\mathrm{BWER}}-\mathrm{BWER}|
\le
\operatorname{AVaR}_{\beta,\mu}(e)
+\mathbb E_\mu[e].
\]

这提供了第二条认证路径：先用空间/cluster-aware simultaneous bootstrap 得到群体风险置信带，再传播为 BWER 区间。它天然允许尾部由数据选择，直接对应 [Cherian & Candès 的 fairness auditing simultaneous inference](https://www.jmlr.org/papers/v25/23-0739.html)。

### 3.4 AlphaEarth 正式证据链存在，但本地统一包陈旧

Google Drive 只读核对确认：

- [AlphaEarth full v2 150k](https://drive.google.com/drive/folders/1kSgz0mJnCASuV2o24JR6A6nPxQEXB6g4) 包含 156,246 行、111 国、完整概率、空间块、BWER、Standardised、Selective、Conformal、Dynamic World、尺度敏感性和 CI 产物；
- [unified package v4](https://drive.google.com/drive/folders/1arsojMyIbmA6oqjUm0gCNlv9HV3cOCpe) 已把 AlphaEarth 标为 `formal_v2_150k`；
- 本地 `outputs/unified_paper_package_v4` 仍是早期 `missing_full_export` 占位版本。

因此 AlphaEarth 不是缺实验，而是需要把 Drive 正式包同步为唯一 canonical lineage，并禁止旧本地占位包继续进入稿件。

### 3.5 AlphaEarth conformal 形成了更强的空间转移现象

目标 90% coverage 时，空间块测试集实测 marginal coverage 为 88.99%，平均集合大小 1.449。目标 70% 时平均集合大小为 0.819，说明存在空预测集的可能。最终 Conformal-BWER 卡必须增加：

- coverage debt：目标覆盖率减实际覆盖率；
- empty-set rate；
- singleton/multi-label set rate；
- 各切片 coverage 与 set size；
- 明确空间块转移下的经验覆盖，而不是把交换性保证直接外推。

这不是削弱结果，而是形成一个清楚的 GeoFM 现象：在空间分布转移下，边际校准的可靠性承诺会产生地理覆盖债务，而 BWER 能定位承担债务的切片。

### 3.6 打包层存在重复 claim 与版本命名冲突

Drive `claim_support_table_v4.csv` 中尺度敏感性和 conformal claim 出现重复行；应在最终 packaging 以稳定 claim ID 去重。当前代码/文档又使用“BWER v2 post-hoc”表示流水线版本，未来若继续公开写“BWER2”会造成歧义。最终论文和 API 只使用：

- `BWER`：最终 weighted fractional 定义；
- `legacy_whole_slice_bwer`：旧 `ceil` 消融；
- `metric_version=bwer_fractional_1.0`：软件版本；
- `Certified BWER Profile`：P15 产品名。

## 4. 是否需要正式 benchmark

不需要建设 leaderboard、数据托管和持续运营型 benchmark。最优定位是：

> 一篇指标/框架论文，附带一个四任务 GeoFM Fairness Validation Suite。

这个 suite 固定数据、协议、模型输出合同、切片定义、损失、部署权重、推断和结果卡，但不承诺社区排行榜运营。它足以证明可复用性，同时把论文中心保持在公平指标上。

## 5. 是否需要新增任务或模型

### 决策

- **第五个任务：不作为必需项。** 当前四任务已覆盖单标签、多标签、分割、全球地图协议，以及事件、地理、传感器条件和空间尺度四类部署轴。
- **新增现代模型：高价值，推荐。** 现有项目共有 Prithvi、DOFA、CROMA、AlphaEarth 四类 FM，但每个真实任务内部的 FM 对照仍偏浅。
- **最优新增不是随机再加模型，而是同一协议的 model × modality panel。**

### 最优模型增补

1. **TerraMind × Sen1Floods11：最高优先级。** 官方仓库已有 Sen1Floods11 多模态配置，且支持 Sentinel-1/Sentinel-2；可与 Prithvi、CROMA/DOFA 和 U-Net 在同一 PANGAEA/TerraTorch 协议下比较。[TerraMind ICCV 2025](https://openaccess.thecvf.com/content/ICCV2025/papers/Jakubik_TerraMind_Large-Scale_Generative_Multimodality_for_Earth_Observation_ICCV_2025_paper.pdf)，[官方代码](https://github.com/IBM/terramind)。
2. **TerraMind × reBEN 三模态：高优先级。** 与 CROMA 形成 `2 architectures × {S1,S2,S1+S2}` 因子设计，检验“融合降低尾部差距”是否跨架构成立。
3. **DOFAv2 × fMoW-Sentinel：中高优先级。** 保留 DOFA v1，新增官方当前权重，检验排名反转是否依赖旧 backbone；DOFA 官方明确支持 Sentinel-1、Sentinel-2 和任意通道输入。[DOFA 官方仓库](https://github.com/zhu-xlab/DOFA)。
4. **PANGAEA 同协议外部复制：高优先级但不新增任务。** PANGAEA 已支持 Sen1Floods11、CROMA、DOFA、Prithvi、监督 U-Net 等，可以把现有洪水协议不一致问题转化成一个标准化 anchor panel。[PANGAEA 官方仓库](https://github.com/VMarsocci/pangaea-bench)，[论文](https://arxiv.org/abs/2412.04204)。

SkySense V2/++ 同样支持 SAR/光学并具有很强代表性，但在 TerraMind 已进入两个关键任务后，继续加入它主要增加模型数量。除非其官方权重和同协议适配显著更顺畅，否则放在附录候选即可。[SkySense CVPR 2024](https://openaccess.thecvf.com/content/CVPR2024/papers/Guo_SkySense_A_Multi-Modal_Remote_Sensing_Foundation_Model_Towards_Universal_Interpretation_CVPR_2024_paper.pdf)。

### 关于“项目没有 SAR 大模型”

该判断不成立：

- reBEN/CROMA 的 `SAR` 模式使用 Sentinel-1 VV/VH；
- CROMA 的 `both` 模式使用配准的 S1+S2；
- DOFA 注册和官方示例也支持 Sentinel-1 SAR。

准确的缺口是：Sen1Floods11 正式主链目前是 S2 洪水分割，没有一个严格同协议的原生 SAR-GeoFM 分割面板。TerraMind/PANGAEA 增补正好解决这一点。

## 6. 优化后实验相对旧版本会好多少

| 维度 | 旧 BWER1 项目 | 完成 P15 后 | 改善来源 |
|---|---:|---:|---|
| 总体参数正确性 | 5.5/10 | 9/10 | 精确尾部质量、显式部署测度、嵌入与包络 |
| 有限样本可信度 | 3/10 | 8–9/10 | selection bias theorem、证书、cluster inference、coverage gate |
| 模型比较有效性 | 5/10 | 8.5/10 | common support、paired CI、同协议 anchor panel |
| 空间有效性 | 5/10 | 8/10 | spatial block、MAUP/SPAD、空间覆盖债务 |
| 跨任务复用性 | 7.5/10 | 9/10 | 固定风险接口和任务适配器 |
| 解释性与采用潜力 | 7/10 | 9/10 | 一个核心参数、固定 profile、机器可读协议签名 |
| 顶刊审稿防御力 | 5/10 | 8.5/10 | 理论、反例、统计认证和现代模型复制 |

新结果不保证数值更大，但会更有科学冲击力：

- 排名反转从点估计现象升级为带配对区间的部署结论；
- “融合改善最坏尾部但不改善全分布 EB-TV”可成为机制发现；
- AlphaEarth 的规模敏感性从“样本更多 BWER 更大”升级为 audit discovery power 与空间覆盖债务；
- 一些旧的巨大 BWER 可能在认证后缩小，但保留下来的差距更可信、更容易成为社区参照。

## 7. 条件成功概率

用户给定“当前 BWER1 版本顶刊概率为 50%”作为校准基线时，本轮给出的主观条件判断为：

| 完成层级 | 顶刊概率区间 |
|---|---:|
| 只把公式换成 fractional BWER | 54%–59% |
| 完成 P15 估计、推断和仿真验证 | 65%–73% |
| 再修复四任务协议、同步 AlphaEarth lineage | 70%–78% |
| 再完成 TerraMind/PANGAEA 同协议模型面板，并得到至少两个可确认机制结果 | **76%–84%** |

中心估计约为 **80%**。这不是统计概率，而是以 RSE/ISPRS JPRS 级别的方法与实证要求进行的项目风险评估。最主要的上升来自有限样本认证和同协议比较；盲目增加第五个任务预计只增加 0–2 个百分点，并可能稀释中心贡献。

## 8. 最终执行顺序

1. 同步 Drive 正式 AlphaEarth v2 与 unified v4，建立唯一 canonical manifest。
2. 冻结最终 BWER 人口参数、三个定理、协议签名和无效状态。
3. 实现 fractional weighted core、common support、strict standardisation、tie/boundary 输出。
4. 修复 cluster bootstrap，并实现 apparent point + honest certificate + simultaneous-band propagation。
5. 通过仿真门：bias、RMSE、coverage、power、ties、异支持、空间相关、MAUP、模型配对。
6. 对现有四任务先做纯 post-processing，确认哪些结论存活。
7. 一次性补齐 fMoW full probabilities、Sen1 probability maps 等确有必要的字段。
8. 用 PANGAEA/TerraTorch 建立 TerraMind 同协议 anchor panel；fMoW 再补 DOFAv2。
9. 四任务一次性正式重算、封装、绘图和写作。

在第 5 步通过之前不启动大规模新模型运行；通过后不再修改主公式，除非预注册的证伪条件触发。
