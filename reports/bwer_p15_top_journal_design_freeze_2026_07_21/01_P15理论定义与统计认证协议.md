# P15 理论定义与统计认证协议

日期：2026-07-21  
状态：设计冻结稿；通过本文件末尾的验证门后再进入正式实现。

## 1. 最终研究对象

P15 的核心不是“找到样本中最差的几个切片”，而是估计如下总体参数：在预先声明的部署分布下，风险最高的 `β` 比例部署质量相对平均部署风险多承担多少损失。

设切片集合为 \(\mathcal G\)，任务损失 \(L\in[0,1]\)，切片风险为

\[
R_g=\mathbb E[L\mid G=g],
\]

预先声明的部署权重为 \(\mu_g\ge 0\)，且 \(\sum_g\mu_g=1\)。部署平均风险为

\[
m_\mu=\sum_g\mu_gR_g.
\]

定义尾部风险

\[
T_{\beta,\mu}(R)
=\inf_{\eta\in\mathbb R}
\left\{
\eta+\frac{1}{\beta}
\sum_g\mu_g(R_g-\eta)_+
\right\},
\qquad 0<\beta\le 1,
\]

最终 BWER 为

\[
\boxed{
\operatorname{BWER}_{\beta,\mu}(R)
=T_{\beta,\mu}(R)-m_\mu
}
\]

它的单位与任务损失一致。BWER 为 0 表示在所声明切片、权重和损失下没有可见的切片风险差异；它不表示模型准确，也不表示社会公平已得到满足。因此结果卡必须同时报告 \(m_\mu\)、\(T_{\beta,\mu}\) 与 BWER。

## 2. 风险包络及可解释性

同一尾部风险可以写成

\[
T_{\beta,\mu}(R)
=\sup_{w}
\sum_g\mu_gw_gR_g,
\]

其中

\[
0\le w_g\le \frac{1}{\beta},
\qquad
\sum_g\mu_gw_g=1.
\]

所以 BWER 的含义是：允许审计者把部署质量向高风险切片进行不超过 \(1/\beta\) 倍的最坏合法重加权后，风险相对原部署平均值最多会上升多少。这个表达比“最差 k 组平均”更一般，也解释了分数边界质量不是一个字面意义上的“半个国家”，而是尾部风险分布的精确积分。

## 3. 必须进入论文的总体性质

### 命题 1：旧 BWER 的嵌入

当 \(G\) 个切片等权，且 \(\beta=k/G\) 时，最终 BWER 等于旧版最差 \(k\) 个切片的平均风险减全部切片平均风险。因此旧 BWER 不是被推翻，而是最终定义的一个离散特例。

非整数尾部由边界切片的分数质量精确补足。论文应将其表述为 AVaR 风险包络下的规范扩展，而不声称在所有可能公理下“唯一”。

### 命题 2：端点与单调性

在有限切片风险下，

\[
\lim_{\beta\downarrow0}\operatorname{BWER}_{\beta,\mu}
=\max_gR_g-m_\mu,
\]

且

\[
\operatorname{BWER}_{1,\mu}=0.
\]

当 \(\beta\) 增大时，BWER 不增。固定的一小组 \(\beta\) 因而形成从最坏切片差距到总体均值的风险剖面，而不是事后挑选最显著的 \(\beta\)。

### 命题 3：质量保持的切片克隆不变性

若一个切片被拆成风险相同、总部署权重不变的多个子切片，BWER 数值保持不变。这解决了等权 `ceil(βG)` 对任意切片数量敏感的问题。它不等于对任意细分都不变：若细分揭示了真实风险异质性，参数应当改变。

### 命题 4：plug-in 的选择乐观偏差

记

\[
D(R)=T_{\beta,\mu}(R)-m_\mu.
\]

由于 \(T\) 是线性函数的上确界，\(D\) 是凸函数。若固定支持下 \(\widehat R\) 对 \(R\) 无偏，则 Jensen 不等式给出

\[
\mathbb E[D(\widehat R)]\ge D(R).
\]

因此全样本 plug-in BWER 会把噪声较大的切片选进尾部，即使所有切片真实风险相同也会得到正值。这不是少数洪水事件才存在的问题；大量低支持国家×类别切片同样严重。

### 命题 5：独立确认是总体 BWER 的有效下界

发现集 A 只负责选择一个满足风险包络约束的权重 \(w^A\)。在独立评估集 B 上估计

\[
d(w^A,R)=\sum_g\mu_g(w_g^A-1)R_g.
\]

因为 \(w^A\) 只是可行解，必有

\[
d(w^A,R)\le D(R).
\]

所以固定该方向后对 \(d(w^A,R)\) 构造的单向下置信界，也是总体 BWER 的单向下置信界。Repeated cross-fit 的科学角色因此是“可复现尾部差距证书”，而不是冒充有限样本无偏的 oracle BWER 点估计。

### 命题 6：同时风险带向 BWER 的传播

若以至少 \(1-\alpha\) 的同时覆盖率得到

\[
|\widehat R_g-R_g|\le e_g,\quad \forall g,
\]

则同一事件上

\[
|D(\widehat R)-D(R)|
\le
T_{\beta,\mu}(e)+\mathbb E_\mu[e].
\]

这给出一条允许尾部由数据选择的认证路径：先用空间/事件/地点聚类的 multiplier bootstrap 建立全部切片风险同时带，再传播到 BWER。它与 Cherian 和 Candès 的同时公平审计思想一致，但这里的目标函数是部署加权尾部风险。

## 4. 估计量与证据必须分层

正式结果不得只给一个数字。P15 的固定输出层级为：

| 输出 | 作用 | 是否主结果 |
|---|---|---|
| 全样本 apparent plug-in BWER | 描述观测到的尾部差距 | 是，但明确为描述性点估计 |
| bootstrap bias-corrected BWER | 修正选择乐观偏差的候选点估计 | 仅在仿真校准通过后 |
| honest confirmed contrast | 独立数据上复核发现的尾部方向 | 是 |
| 单向 certified LCB | 证明至少存在多大的可复现差距 | 是 |
| paired model-difference CI | 判定模型尾部排名或反转是否可靠 | 是 |
| empirical-Bayes/shrinkage BWER | 小支持敏感性分析 | 否，不替换主参数 |

本轮仿真直接否定了“选一个估计量包办所有用途”：plug-in 偏高，cross-fit 作为 oracle BWER 点估计偏低，简单经验贝叶斯在真实尾部存在时也会压缩信号，严格浓缩不等式下界则可能过于保守。

## 5. 当前仿真结论

脚本与全部输出位于：

- `p15_estimator_stress_test.py`
- `diagnostics/population_property_checks.csv`
- `diagnostics/standardisation_counterexample.csv`
- `diagnostics/cluster_clone_counterexample.csv`
- `diagnostics/estimator_simulation.csv`
- `diagnostics/split_allocation_simulation.csv`

用 fMoW 正式资产中 145 个有效国家的真实支持分布进行 500 次重复模拟，得到：

| 场景 | 真 BWER | plug-in 均值 | cross-fit 均值 | bootstrap 修正均值 |
|---|---:|---:|---:|---:|
| 同质零假设 | 0.0000 | 0.1088 | 0.0008 | 0.0733 |
| 中等尾部 | 0.0538 | 0.1121 | 0.0107 | 0.0792 |
| 强尾部 | 0.1076 | 0.1299 | 0.0444 | 0.1060 |

名义 95% 的普通 Wald 单向下界在零假设下覆盖率仅约 92.8%，假阳性约 7.2%，不能作为默认认证。Hoeffding/Bernstein 有限样本下界在这些模拟中覆盖充分，但对中等信号非常保守。由此冻结以下策略：

1. 描述点估计用全样本 plug-in，并同时展示支持量与偏差校准结果；
2. 主实用区间使用 cluster/spatial multiplier bootstrap，但必须先通过覆盖率模拟；
3. honest split 作为独立确认路径；
4. 有界损失的 Hoeffding/Bernstein LCB 作为严格保底证书；
5. 普通 Wald 区间只可作为大样本诊断，不进入默认报告卡。

cluster/slice 同一时的构造例也复现了现有实现的目标错误：一次事件超总体 bootstrap 若抽到风险 `[1,1,0]`，正确的三次抽样经验分布在 `β=.5` 下 BWER 为 0.3333；保留原事件 ID 后 group-by 折叠成 `[1,0]`，BWER 变为 0.5。它不是数值精度问题，而是推断总体被静默改变。

## 6. 支持、权重和协议签名

任何一个 BWER 数字都必须绑定如下协议签名：

```text
task / loss / prediction_unit / slice_definition /
deployment_weights / beta / support_rule / missingness_rule /
split_protocol / inference_unit / reference_product /
metric_version
```

缺少其中任一会改变科学问题的字段时，不允许跨模型直接排名。

### 支持规则

- 支持阈值必须在看模型性能前确定；
- 报告保留的部署质量，而不只报告有效切片个数；
- `classification` 的样本支持与 `segmentation` 的像素支持分开；
- 相邻像素不是独立重复，Sen1Floods11 的推断单位优先是事件或图块；
- 国家×类别等高维切片必须额外报告有效质量、最小支持、尾部成员稳定性和发现 multiplicity。

### 部署权重

- `equal_slice` 回答“随机选择一个切片”的公平性问题；
- `empirical_exposure` 回答当前样本/部署流量问题；
- 领域给定权重回答目标部署人群问题；
- 主权重必须预注册，只保留一个有实质含义的敏感性权重；
- 不将多套权重中结果最大的一个作为主结论。

## 7. Standardised-BWER 的最终定义

给定需控制的组成变量 \(Z\) 与固定目标分布 \(q_z\)，标准化风险为

\[
R_g^{\rm std}=\sum_z q_zR_{gz}.
\]

其可识别性要求：所有 \(q_z>0\) 的层在每个比较切片中均有充分支持。现有逐组 `renormalize` 会让每个切片使用不同的目标分布，不能被解释为控制组成后的公平差距。

本轮构造的反例为：A 组两类别风险分别为 0.1、0.9；B 组只观察到第一类且风险 0.1；目标分布为各 50%。逐组重归一化得到 A=0.5、B=0.1，制造 0.4 的表面差距；严格共同支持上二者均为 0.1。

最终规则：

1. 主分析使用 strict common-support direct standardisation；
2. 若目标质量缺失，返回 `not_identified`，并报告缺失质量；
3. 可在有足够理由时使用预先声明的层级模型或部分识别上下界；
4. 旧 `renormalize` 只保留为兼容性诊断，不能再命名为正式 standardised BWER。

## 8. 模型比较与排名反转

对模型 A、B，应在性能未知时确定共同有效切片集合 \(\mathcal G_{AB}\)，然后计算

\[
\Delta D=D(R^A;\mathcal G_{AB})-D(R^B;\mathcal G_{AB}).
\]

必须对同一事件、位置或空间块进行成对重采样，并在每个 bootstrap replicate 内重新计算完整尾部泛函。只比较两个独立 BWER 区间是否重叠并不是正确的差值检验。

“平均风险排名与 BWER 排名反转”只有在以下条件同时成立时才能成为正式结论：

- 平均风险差的配对区间不跨 0；
- BWER 差的配对区间不跨 0；
- 两个差异方向相反；
- common-support、固定 \(\beta\) 和固定部署权重下成立；
- 至少一个协议/模型复现中方向稳定。

## 9. Selective、Conformal 与其他成员的统一方式

P15 不把每种模块改名成互不相干的新指标，而是更换风险输入：

- Raw-BWER：\(R_g=\mathbb E[L\mid g]\)；
- Standardised-BWER：\(R_g=R_g^{\rm std}\)；
- Selective-BWER：在预注册覆盖率 \(c\) 下，用被接受样本的任务损失作为 \(R_g(c)\)，同时报告组覆盖率差；
- Conformal-BWER：\(R_g\) 为误覆盖率或预注册 conformal risk，同时报告边际覆盖、最差切片覆盖、集合大小和 coverage debt；
- Rich-LCB：将每组点风险替换为预注册的一侧保守风险界，作为敏感性模块；
- EB-TV：描述全切片风险分布的总变差负担，作为伴随量而不是第二主指标；
- 空间邻域/MAUP 模块：检验切片定义与尺度稳定性，不替代核心 BWER。

Selective 与 Conformal 不相互替代：前者回答“拒绝低置信样本后，保留业务的尾部风险如何”；后者回答“具有目标覆盖的集合/风险承诺在哪些切片失效”。

## 10. 推断总体必须先区分

事件恰好同时是切片和最高层独立单位时，存在两个不同目标：

1. **固定事件集合目标**：描述这 11 个已知洪水事件；在事件内部对空间块/图块进行相关性稳健推断；
2. **事件超总体目标**：把现有事件视为未来灾害事件抽样；对事件重采样，此时每次抽中的事件复制必须拥有 replicate 内唯一 ID，不能重新合并为同一个原事件。

代码当前的 cluster bootstrap 在 `cluster_key == slice_variable` 时会把重复抽中的同名事件重新聚合，改变 bootstrap 目标。修复时必须显式选择上述总体，不能只改一行 ID 后声称两种解释均成立。

## 11. 实现前必须通过的验证门

### 数学单元测试

- 等权整数 \(\beta G\) 精确嵌入旧版；
- \(\beta\downarrow0\) 与 \(\beta=1\) 端点；
- BWER 随 \(\beta\) 不增；
- 质量保持的同风险克隆不变；
- ties 下数值对排列不变；
- 分数边界质量总和精确为 \(\beta\)；
- 损失仿射变换的尺度性质；
- 常数风险向量返回 0。

### 统计仿真门

至少覆盖：

- 同质零假设；
- 一个、多个和连续弱尾部；
- fMoW 式长尾支持；
- Sen1Floods11 式小 \(G\)；
- 空间相关强度梯度；
- 边界 ties；
- 缺失层与非 positivity；
- 模型共同支持不一致；
- 平均排名与尾部排名反转；
- 零膨胀、多标签和分割损失。

主 95% 区间需满足：关键零假设和替代情形中覆盖率的 Monte Carlo 置信区间与 95% 相容；若达不到，继续改推断而不是调整展示。主差异检验还需报告 power，不允许用极度保守且几乎永不拒绝的区间换取形式正确。

### 真实数据负控

- 切片标签置换：在保持支持分布时 BWER 应回到模拟零基线；
- 风险相同的切片克隆：总体参数不变；
- 随机伪切片：不得稳定地产生可确认的机制结论；
- 空间块尺寸变化：报告 MAUP 敏感性而非挑选最强结果；
- 参考产品切换：区分模型误差与地图分歧。

## 12. 冻结结论

P15 的最佳形式仍然以 BWER 为唯一核心风险函数，但它比 BWER1 多出四个决定论文水平的层次：精确的 fractional population estimand、显式部署测度、有限样本选择偏差处理、空间/聚类条件下的可认证推断。P15 不是“BWER2 再加 P15 辅助公式”；P15 是最终审计产品，BWER 是其核心参数，证书与协议是让该参数可被可靠复用的必要组成。

最关键的新增科学主张不是“CVaR 第一次被使用”，而是：GeoFM 公平评估可以被表述为一个带部署测度、任务风险接口、共同支持条件和有限样本证书的地理尾部风险审计问题，并且同一审计合同可跨分类、多标签、分割和全球地图协议运行。
