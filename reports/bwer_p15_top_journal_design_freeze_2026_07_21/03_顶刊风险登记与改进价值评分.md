## 2. 指标矩阵：哪些是 BWER，哪些不是

### 核心 BWER 家族

所有成员使用同一尾部差距泛函，只改变预先声明的切片风险：

| 名称 | 风险输入 | 回答的问题 | 正文地位 |
|---|---|---|---|
| Raw-BWER | 原始任务损失 | 哪些部署切片承担更多任务错误 | 核心 |
| Standardised-BWER | 共同目标组成下的标准化风险 | 控制类别/组成后差距是否仍在 | 核心或主要机制 |
| Selective-BWER | 固定业务覆盖率下的接受样本损失 | 模型拒绝低置信样本后，剩余业务是否仍不均 | 主要扩展 |
| Conformal-BWER | 误覆盖或预注册 conformal risk | 覆盖承诺在哪些地理/语义切片失效 | 主要扩展 |
| Max-BWER | \(\beta\downarrow0\) 的极限 | 单一最坏切片相对均值多差 | comparator，不作主指标 |
| BWER profile | 固定 \(\beta\in\{.05,.10,.20,.30\}\) | 结论是否只依赖一个尾部尺度 | 核心稳健性 |
| Certified BWER | 对 selected contrast 的一侧下界 | 至少多少尾部差距能被独立确认 | 证据层，不是新总体参数 |

### 必须共同报告但不叫 BWER

| 量 | 作用 |
|---|---|
| mean risk \(m_\mu\) | 防止“所有切片同样差却 BWER=0”的误读 |
| tail risk \(T_{\beta,\mu}\) | 展示最差部署质量的绝对可靠性 |
| worst-group gap / max-min gap | 与最常见最坏组公平指标对照 |
| EB-TV / Gini / Theil | 展示全分布不平等，证明 BWER 不是简单重述 |
| support mass / missing mass | 可识别性与部署覆盖 |
| tail membership stability | 尾部身份是否稳定 |
| coverage debt / set size | conformal 合格性与实用性 |
| paired difference CI | 模型排序和排名反转是否成立 |

## 4. 仍未完全解决、必须继续验证的问题

### 4.1 实用主区间尚未选定

当前已证明普通 Wald 不够可靠、严格 Hoeffding/Bernstein 在现有支持下可能过保守。下一步要比较 spatial block bootstrap、cluster multiplier bootstrap、studentized bootstrap 与 honest split，并以覆盖率和 power 双门决定主区间。不能只凭区间较窄选择方法。

### 4.2 BWER 点估计仍不存在“全场景最优者”

parametric bootstrap 修正在强尾部和小 \(G\) 场景表现很好，但在同质 fMoW 支持下仍有约 0.073 的正偏差；cross-fit 接近零假设，却在真实尾部下因尾部误选明显偏低。因此保留 apparent point + certificate 是当前最诚实且最有解释力的产品设计。

### 4.3 \(\beta\) 与 \(\mu\) 必须由科学问题冻结

不存在不含规范选择的万能公平数。推荐主结果使用 `BWER@10`，并固定 `.05/.10/.20/.30` profile；国家宏权重和经验部署权重不可混成一个最优值。模型排名只在同一签名下比较。

### 4.4 社会公平与部署切片可靠性边界

国家、事件、地理位置、类别和 sensor condition 的伦理含义不同。论文可以将 BWER 定位为 GeoFM deployment-slice fairness/reliability metric，但必须把“高错误风险切片”与“因果歧视”区分。这个边界不会削弱工作，反而使指标适用范围更可信。

### 4.5 社区采用不能由单篇论文保证

“成为默认指标”需要一行 API、版本化协议卡、清晰默认值、无效状态、独立复算和后续模型报告采用。本文能做到的是把成为标准的技术条件一次性做好，并争取做出首个成熟、可复用的 GeoFM deployment-slice fairness audit standard；不能把未来采用率当成已完成实验结论。

## 5. 最终 top-journal 写作策略

主稿应积极围绕三个贡献组织：

1. 一个严格定义、任务无关的部署尾部不公平参数；
2. 一个解决尾部选择、共同支持和空间相关的认证协议；
3. 一个横跨四类 EO 任务、揭示排名反转、多模态尾部效应和 coverage debt 的验证套件。

不需要在摘要里列出所有工程缺陷，也不需要用“我们没有发明 CVaR”作开场；但文献定位、方法条件、无效状态和真实限制必须准确。顶刊叙事可以聚焦发现与解决方案，不能依赖审稿人遗漏会改变结论的 bug。

## 6. 概率与增益判决

以用户给出的“当前完成 BWER1 后顶刊概率 50%”作为共同主观基线：

| 完成状态 | 条件性顶刊概率 | 相对提升 |
|---|---:|---:|
| 当前 BWER1 直接包装 | 50%（给定基线） | — |
| 仅替换 fractional 公式 | 54–59% | +4–9 点 |
| 再完成 P15 推断与仿真 | 65–73% | +15–23 点 |
| 再完成四任务协议修复、AlphaEarth lineage | 70–78% | +20–28 点 |
| 再完成 TerraMind/PANGAEA 因子面板和至少两个认证机制结果 | **76–84%** | **+26–34 点** |

中心估计约为 **80%**。它是项目规划判断，不是可频率解释的统计概率。最主要的提升来自：把一个有趣但易受支持量影响的分数，升级为定义明确、能推断、能跨任务复算、并由现代 GeoFM 因子实验支持的方法学框架。

若新增模型后所有“震撼”现象均不复现，概率不会自动降回 50%；只要方法验证充分，得到“许多表面尾部差距来自选择噪声，真正可确认的差距更少”本身也可成为强方法学结果。反之，若只增加模型数量而不解决 R2–R6，概率提升很小。
