# GeoBWER Certification 1.2：实施结果与冻结证据重审

日期：2026-08-09
软件版本：0.5.0
点估计版本：`geobwer_fractional_1.1`（未修改）
认证版本：`geobwer_certification_1.2`

## 1. 本轮结论

本轮没有重训模型，也没有改变 GeoBWER 点公式。升级的实质是把“一个可计算的点值”与“一个可发表的正式证据”分开：任何正式主张现在都必须绑定风险定义、estimand、切片全集、deployment measure、依赖设计、cluster eligibility 校准及认证版本。

前半段高价值工作包已经落地：

1. 建立 canonical evidence registry，明确 canonical source、canonical derived、descriptive-only、revoked 和 debug-only 身份；
2. 建立 `RiskSpec` 和 `EstimandIdentity`，防止不同损失、切片宇宙、权重或支持集的结果被误比较；
3. 修复空间校准 gate：从错误的“CI 与门槛有重叠即可”改为预注册单侧置信界必须通过；
4. 建立统一 cluster eligibility taxonomy：not observed、descriptive only、inferentially eligible；
5. 实现 Certification 1.2：sharp simultaneous-box bounds、M/T/D 联合区间、paired comparison、partial identification、tail regime 与 no-harm/levelling-down 判决；
6. 提供只读 frozen-output re-audit runner，源文件 SHA 在重审前后必须一致，新证据只能写入新目录。

## 2. Material Passport

本轮使用的冻结资产由 `configs/analysis/canonical_evidence_registry_v1.yaml` 统一登记。核心来源包括：

- fMoW：DOFAv2、common-9-band ResNet-50 及 frozen superclass panel；

## 3. 方法升级

### 3.1 RiskSpec 与 estimand identity

`RiskSpec` 冻结：风险名称、方向、上下界、独立单位、聚合方式、reference、ignore policy、阈值来源、任务适配器和类别映射。GeoBWER 只接受 `higher_is_worse` 的有界风险。

`EstimandIdentity` 将以下因素哈希为一个可比较性身份：RiskSpec、axis、fixed group universe、deployment measure、beta、partition、standardisation/missingness、dependence design 及 common-support 口径。身份不一致的两个 GeoBWER 不再被 API 默认为同一参数。

### 3.2 空间校准 gate

旧实现实质要求：coverage CI 上界达到目标、FPR CI 下界不超过上限。这会让高度不确定的失败设计通过。

新实现要求：

- `coverage_ci_low >= confidence_level - coverage_tolerance`；
- `false_positive_ci_high <= alpha + false_positive_tolerance`。

候选空间尺度还必须满足 range adequacy；power 与 validity 分离，只有预注册要求时才作为硬 gate。

### 3.3 Cluster eligibility

正式 reference stress simulation 使用 unequal support、repeated rows、ICC=0.5、共同零假设和 tail ties。冻结模拟中，2–50 clusters/group 均未同时通过单侧 coverage/FPR gate，75 clusters/group 首次通过：coverage 0.946、FPR 0、coverage CI `[0.9226, 0.9626]`、FPR CI `[0, 0.0076]`。

75 是该 reference stress design 的默认下界，不是宣称适用于所有 EO 数据的自然常数。任务若有严格 validation-only、layout-specific calibration，可以用其冻结签名替代默认门槛；没有签名时只保留描述性点值，不产生认证区间。

### 3.4 Certification 1.2

新认证把 simultaneous group-risk band 映射为：

- mean risk 区间；
- tail risk 区间；
- GeoBWER 的 sharp/可审计区间；
- paired `Δmean / Δtail / ΔGeoBWER`；
- `certified_no_harm_improvement`、`disparity_reduction_with_tradeoff` 或 `no_certified_disparity_reduction`；
- `worst_slice / near_worst_slice / multi_slice_tail` 和 tail capacity/effective groups。

等切片 deployment measure 的上界使用 capped-simplex extreme-point 解；下界使用 CVaR epigraph breakpoint 解。小规模任意权重用精确 box-vertex 解，大规模任意权重才回退到透明的保守界。完全支持时 partial-ID 严格退化为原点估计。

## 4. 冻结证据裁决

### 4.1 fMoW-Sentinel

已对本地冻结 DOFAv2 正式表执行真实 CPU-only 1.2 重审，四个表（主表及 seeds 42/73/101）均完成，源文件未修改。

保留：

- 点现象稳定：country GeoBWER 为 0.1972、0.2128、0.2107；
- region 约 0.1501，un-region 约 0.066–0.092，continent 约 0.078–0.080；
- class 与交叉切片存在明显 tail saturation；
- frozen paired panel 中，Region×Superclass 和 Country×Superclass 的“更小差距”主要来自 mean risk 变差而 tail 已饱和，属于 levelling-down，而不是公平改善。

重新认证：

- DOFAv2 各轴现在为 `formal_partial`；例如 seed 42 的 region partial-ID 为 `[0.0047, 0.6613]`，un-region 为 `[0.0066, 0.3131]`，continent 为 `[0.0050, 0.4138]`；country 与 class 的下界仍为 0；
- `resolved_region` 的 DOFA–ResNet 配对方向仍最值得正式确认：三 seed 中 DOFA tail risk 低约 0.034、GeoBWER 低约 0.028，但需用同一 common-support 表运行 paired 1.2 后才能称为模型差异认证。

撤销/降级：

- 不能仅凭旧的宽 CI 或较小 GeoBWER 宣称某模型“更公平”；
- Country×Superclass 只有 46/1328 单元支持，保留为 supported-cell exploratory；Region×Superclass 76/168、样本覆盖约87.1%，保留为 secondary exploratory，不冒充理论笛卡尔全集。

### 4.2 reBEN

保留：

- 27-run 点趋势稳定：S2/S1+S2 通常优于 S1；TerraMind S2 与 fusion 的 mean/tail/GeoBWER 最低；ResNet S1 seed 波动最大；
- 代表性三 seed 均值：TerraMind S2 `M=0.0883, T=0.1193, D=0.0310`，CROMA fusion `0.0948/0.1315/0.0366`，ResNet S1 `0.1443/0.1931/0.0488`。

撤销/降级：

- 10个 country 的独立 cluster 数仅为 1–17（最高 Finland=17）；旧的“7个 supported countries 可作正式推断”不再成立；
- 所有 country GeoBWER 点值保留为描述性，固定10国全集改用 partial identification；当前证据不能认证细小的跨模型 GeoBWER 排名差。

下一步只需读取现有概率和逐样本表，执行任务特异的 cluster calibration 或 1.2 partial-ID/paired 后处理；无需重训27个模型。

### 4.3 AlphaEarth

保留：

- v2 是唯一 canonical AlphaEarth 证据；24030 test 与22818 calibration 严格空间分离；
- raw 点现象保留：country `M=0.2287, T=0.3498, D=0.1211`，class `D=0.1813`，country×class `D=0.3402`，region×class `D=0.2280`，urban proxy `D=0.0568`；
- ordinary conformal 与 geo-kernel comparator 的效率现象保留：局部方法 coverage 约提高0.006，但平均 set size 同时增加约0.37；它仍只能表述为 empirical geographic localization comparator。

撤销/降级：

- 旧 class LCB 0.0427、urban LCB 0.0235 不能继续作为正式认证；旧配置明确是 `legacy_block=0.5_degree_sensitivity_only` 且 `small_cluster_calibrated=false`，并使用了现已修正的 gate；
- biome/ecoregion 因 test 元数据全缺失，仍不识别；
- country×class 的 fixed universe 是冻结测试人口中观察到的组合全集，不是 111×11 理论笛卡尔全集。

AlphaEarth 应在 validation-only 数据上重新运行修正后的空间尺度校准；若无尺度通过，点值和 uncertainty comparator 仍可保留，但正式 spatial LCB 必须保持撤销。无需重跑 GEE、embedding 或 probe。

## 6. 验收与测试

已通过的关键验证包括：

- sharp equal-measure upper 与2–6组全部box vertices穷举一致；
- sharp lower 与两组密集网格一致；
- sharp band 不宽于旧Lipschitz fallback；
- 完全支持的partial-ID精确退化；
- paired no-harm 与levelling-down/trade-off分类；
- tail boundary ties 对命名/排列不敏感；
- RiskSpec/estimand hash、canonical registry和cluster evidence taxonomy；
- 空间gate单侧置信界反例；
- frozen re-audit 源不可变和completion contract；
- AlphaEarth uncertainty派生RiskSpec与既有升级流程兼容。

本机全库回归的一次执行得到 `425 passed, 26 skipped, 18 failed, 94 errors`。其中大量 error 明确来自 Windows sandbox 对 pytest 临时目录的访问拒绝；同时定位并修复了一个由新增 RiskSpec 暴露的 uncertainty 派生协议兼容问题。由于 sandbox 继续阻止 pytest 创建/清理临时目录，未把该次全库结果冒充为 clean pass。修复后，本轮方法、空间gate、frozen re-audit、AlphaEarth兼容和原核心API的合并定向套件为 `68 passed`。

## 7. 下一阶段唯一顺序

1. 在 Drive 上用新 runner 对 fMoW DOFA与ResNet、reBEN 27-run 和 AlphaEarth v2 生成独立的 Certification 1.2 派生目录；不覆盖源目录；
2. 先完成 fMoW same-seed common-support paired 1.2，确认 `resolved_region` 是否达到 no-harm 或仅为方向性结果；
3. 对 reBEN 运行 fixed-universe partial-ID，并决定是否值得做 validation-only task-specific cluster calibration；不重训；
4. 对 AlphaEarth 运行修正 gate 的 validation-only spatial calibration；通过才恢复正式 spatial inference；
5. 生成统一四任务 evidence-status matrix，再进入论文主表、图和叙事冻结；
6. 后半段再处理 cluster-aware conformal/CRC 的理论身份、Sen1描述性结果统一，以及外部用户SDK。它们不应阻塞本轮方法核心落地。

## 8. 最终判断

这次升级提高的不是 GeoBWER 点数值，而是它作为可复用公平性审计框架的可证伪性与可审计性。最重要的科学收益是：项目现在能够区分“发现了尾部差异”“差异对支持/切片定义敏感”“差异被正式认证”“差距下降但总体风险变差”四种完全不同的结论，避免用一个看似精确的公平分数掩盖支持不足、tail saturation 或 levelling-down。
