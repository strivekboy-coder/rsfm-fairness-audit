# GeoBWER 联合科学审查与后续运行判决

日期：2026-07-26
范围：reBEN 27-run、fMoW DOFAv2、fMoW ResNet-50 与冻结 Superclass 后处理。
证据类型：只读检查既有正式输出；本报告没有改变预测、风险、β、支持门槛或 bootstrap。

## 一、执行判决

现有 reBEN 与 fMoW 模型输出不需要重跑。reBEN 已经提供了目前最有力的“平均性能改善不必然等比例改善地理尾部风险”和“全局不确定性控制不保证最差国家控制”证据；fMoW 则提供了互补的困难案例：稀疏交叉切片会使固定全集难以识别，而且单看较低 GeoBWER 会产生 levelling-down 误读。

当前不存在要求重跑某个 seed 的 blocking scientific error。需要做的是 CPU 后处理、联合指标解释和任务适用性标注。fMoW v2 后处理必须联合报告 mean risk、tail risk、GeoBWER，不得将较小的差距单独解释为模型更安全或更公平。

## 二、哪些组件按预期工作

### 2.1 reBEN

- 27 个模型×模态×seed 运行形成一致的正式测试人口，能够进行同任务比较。
- TerraMind 的 S2 与 S1+S2 在总体风险和地理尾部风险上稳定领先；CROMA 居中；监督 ResNet-50 的 S1/S2 更受 seed 影响。
- Selective 审计在各预注册覆盖率上均没有零接收国家，说明选择性风险在该任务中可识别并有实际区分力。
- CRC 的全局平均风险大体接近 0.10 目标，但地理尾部相对目标仍有约 0.04–0.08 的正违反量。这正是框架希望发现的现象：平均不确定性承诺不等于最差部署切片承诺。
- β profile 正常工作。由于 supported country 只有 7 个，β=0.1 的有效尾部约等于一个最差国家；β=0.2、0.3 才逐渐形成多国尾部平均。应在论文中明确解释，而不是把三个 β 当成重复数字。

### 2.2 fMoW

- DOFAv2 与 ResNet-50 使用相同 `sample_id` 配对，并以 `site_id` 处理依赖；三组 seed 标签对齐，但不表示共享随机流。
- Region×Superclass 的 76 个 supported cells 覆盖约 87.1% 测试样本，适合作为支持全集的次级探索分析。
- 精确六单元面板能够产生组风险的同时区间；其同时性仅覆盖“同一 seed 下六个冻结单元”，不覆盖三个 seed 的联合多重性。
- 固定全集 partial bounds 正确暴露了数据不能支持的部署质量，没有通过事后降低门槛制造精确结论。

## 三、哪些结果饱和或无识别力

### 3.1 fMoW Region×Superclass 的尾部饱和

在 76 个 supported cells 上，DOFAv2 和 ResNet-50 的 tail risk 均达到 1.0。DOFAv2 三个 seed 的 GeoBWER 较低，但其 mean risk 反而更高。因此差距缩小主要来自整体表现变差，而不是最差切片改善。这是典型 levelling-down。

结论：这一轴不能用“DOFA 更公平”概括；应写成“两个模型均出现最差交叉切片饱和，GeoBWER 单独排序会受到 levelling-down 影响”。这反而支持 GeoBWER Audit Card 必须联合报告 mean、tail 和 gap 的方法学主张。

### 3.2 fMoW 交叉固定全集

- Region×Superclass：76/168 单元有支持，等单元部署质量覆盖约 45.2%。
- Country×Superclass：46/1328 单元有支持，等单元部署质量覆盖约 3.46%，样本覆盖约 36.9%。

Country×Superclass 的固定全集 partial bounds 几乎没有排序能力，只能作为“审计能力/数据覆盖债务”诊断，不应承担主文的综合交叉公平性结论。

### 3.3 fMoW 配对区间

正式保守区间普遍很宽并包含零；原始区间超出 GeoBWER 差值的理论范围并非计算错误，而是保守映射的结果。v2 同时保留 raw CI，并报告与已知范围 `[-0.9, 0.9]` 的交集。裁剪不会创造显著性，也不能替代原始区间。

### 3.4 reBEN 固定国家全集

10 个固定国家中只有 7 个满足支持要求；full-universe partial bounds 下界为 0、上界很宽，不能认证完整十国排序。supported-universe 结果仍然有解释力，但必须同时报告 97.7% 样本覆盖与 70% 等国家部署质量覆盖。

## 四、GeoConformal / conformal 状态

- 多分类：fMoW 与 AlphaEarth 具备完整概率、校准集和坐标时，可以正式运行 global split conformal 与地理核局部 comparator。v0.4.13 已为两条 campaign 接入 `SpatialConformalConfig`；既有 fMoW 概率可通过现有 `geobwer-spatial-upgrade` CPU 入口补算，无需重新推理。
- 多标签 reBEN：正式 anchor 是 Conformal Risk Control。局部地理核 prediction-set 方法没有在冻结协议下建立多标签保证，因此不应为了“全覆盖”强行套用。v0.4.13 会明确标记 CRC 已完成、局部 Geo 方法在该任务几何下不适用，而不是显示成代码未完成。
- Sen1Floods11 分割：正式 anchor 同样是像素/场景风险的 CRC，加上 Selective 审计。局部 GeoConformal prediction set 不是同一数学对象；代码会明确区分“正式 CRC 完成”和“局部方法未在冻结分割协议中建立”。

## 五、顶刊视角下的优化建议

1. 将核心结果从“一个公平分数”升级为三联风险卡：mean risk、tail risk、GeoBWER。levelling-down 是必须自动诊断的失败模式。
2. 把 reBEN 的“全局 CRC 基本达标、最差国家仍欠覆盖”作为不确定性主现象；它比在所有任务机械复刻局部 GeoConformal 更强。
3. 将 fMoW 定位为支持稀疏与可识别性压力测试，而不是最强效应发现任务；76-cell 结果为次级探索，六单元为预注册局部确认，Country×Superclass 放附录。
4. 主文模型比较优先使用同协议、共同支持、配对差值；跨适配协议结果可作外部有效性证据，但不应伪装成严格性能排行榜。
5. 在 Sen1Floods11 与 AlphaEarth 之前统一迁移下面的报告契约，避免得到结果后再补解释字段。

## 六、运行 Sen1Floods11 与 AlphaEarth 前的通用补丁

- 每个轴始终联合输出 mean、tail、GeoBWER 及其模型差值。
- 自动检测 levelling-down、tail saturation、全部组同差和零接收组。
- 同时报告 fixed-universe、supported-universe、样本覆盖、等切片部署质量覆盖和排除质量。
- 原始 CI 永久保留；有界参数裁剪仅作附加列，不能覆盖原值。
- β profile 输出有效尾部群体数，尤其在事件数/国家数较小时解释 β 的实际含义。
- 明确校准/测试隔离、配对单位、依赖 cluster、seed 对齐含义和同时区间的 family 范围。
- Conformal 输出必须同时报告 global coverage/risk、tail coverage debt、效率（set size 或 prediction-set fraction）以及任务适用性。
- AlphaEarth 的地图标签风险表述为 reference-map disagreement，并保留 WorldCover–Dynamic World ambiguity 分层。

## 七、精确重跑清单

- reBEN：不重跑任何 model/mode/seed。
- fMoW DOFAv2：不重跑模型或 probe；运行 CPU v2 后处理，并可选运行现有概率的 spatial conformal upgrade。
- fMoW ResNet-50：不重跑任何 seed；仅进入 v2 联合后处理。
- Sen1Floods11：按既定正式 campaign 首次运行，不因 reBEN/fMoW 结果新增 GPU 返工。
- AlphaEarth：优先复用既有概率和坐标做正式后处理；只有 lineage 或坐标无法与校准样本精确连接时才考虑重新导出，不默认重新生成 embeddings。
